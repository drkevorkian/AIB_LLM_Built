Ghost White uses #F8F8FF surfaces, black text and #ACE5EE lines. Blizzard Blue uses black surfaces, #ACE5EE text and #F8F8FF lines. Choose either in Settings; the header toggles to its opposite. Dark/Light remains available. Browser preferences persist when storage is available; denied storage leaves the selected theme usable and reports the limitation. Switching appearance preserves mounted composer/upload drafts and conversation records.

Human uploads retain exact original bytes, raw-byte SHA-256 and immutable workspace-scoped version records. Bound each version to 512 KiB and each workspace to 40 versions/8 MiB. Appending a version cannot overwrite previous originals or retarget submitted work. SQLite schema 3 adds a private BLOB table, atomic with room metadata; schema 1/2 upgrades preserve existing data. Whole-workspace and bulk deletion cascade original bytes; thread deletion removes human grants/copied context while independently owned originals remain.

Validate canonical base64, bounded safe filenames, declared supported media, strict UTF-8/JSON and binary signatures. ZIP validation permits a bounded classic stored/deflated subset with 32 regular members, 512 KiB/member, 4 MiB expanded total and 100:1 per-member ratio. Reject unsafe paths, duplicate paths, encrypted/ZIP64/split/data-descriptor/self-extracting records, unsupported methods, inconsistent records, symlinks and nested archive filenames/signatures. No member is written to disk, recursively expanded or executed.

Previews show escaped exact/bounded text, checked ZIP member metadata/hashes or image/PDF/binary metadata. Long text previews disclose omissions and offer full originals separately. Authenticated explicit original downloads are attachment-only application/octet-stream with nosniff/no-store. Previews and uploads make no provider call and consume no turn.

A human question may explicitly select up to four full UTF-8 text versions, each at most 16,000 characters. Review the receiving participant bindings; the human message records exact references and the context copies exact text with version/hash/grant provenance. Sibling first answers share the same evidence independently. Retry, synthesis/late revision and relay/coordinator/peer continuations preserve their root versions despite later uploads. Integrity/grant failures and protected context overflow reject before invocation or turn use. Unselected workspace files, previews and old grants never authorize later provider inclusion.

Stale uploads and unknown acknowledgements require explicit Refresh to inspect current version metadata/command identity; files and edits are retained and POST requests are not automatically replayed. Archives retain read-only previews/downloads.

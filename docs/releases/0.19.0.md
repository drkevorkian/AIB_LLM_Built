## Verification and limits

Three new lint-gate integration tests bring source coverage to 317. The existing 67 Chromium tests remain required: 384 distinct source/browser tests. Negative fixtures verify real failing exits for executable evaluation, malformed syntax, and stale exceptions; positive fixtures retain quoted model data and intentional security filters. Scope tests verify discovery of new client/server/browser/root tooling and exclusion of generated/local-data paths. Fixtures run in isolated temporary directories with bounded child processes and never execute their source or invoke a provider.

Required gates are locked installation, lint, strict TypeScript, all source tests, formatting, production builds, zero-vulnerability production audits, and all Chromium flows on both Ubuntu runtimes. Exact completed commit/tree/run evidence belongs in `LLM_Recovery_Prompt.md`. Local Chromium remains unavailable; browser validation uses CI, without credentialed provider/model requests.

Lint is scoped to syntax and configured correctness rules. It is not type-aware React/compiler analysis, a secret scanner, a complete security audit, or a substitute for runtime tests. Those broader tasks, correction/supersession policies, packaging, and all remaining original checklist work stay open. No new license grant or package publication occurs.

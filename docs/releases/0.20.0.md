# v0.20.0 — Response collection choices and late synthesis

Ordinary questions now support all, any, quorum, or full-window deadline collection. Select a nonempty minimum, choose cancel-and-pause, continued waiting, or an explicitly incomplete timeout outcome, and choose whether remaining recipients continue or are cancelled. No-reply updates still invoke nobody. Relay and coordinator-discussion behavior remains unchanged.

Response cards, context inspection, and exports retain the exact included sources and missing outcomes at closure. Synthesis instructions preserve conflicting claims, their authors, and unresolved questions; missing answers cannot imply agreement. The application records collection facts rather than claiming semantic disagreement detection.

Eligible late answers can feed **Request updated synthesis** after the earlier synthesis completes. The reviewed command creates a separate linked response set, snapshot and synthesis turn using the original task, instructions and participant/model binding. Earlier outputs and closures remain unchanged. Duplicate UUIDs/answer sets, stale reviews, inactive/removed original synthesizers, deleted context and exhausted budgets are rejected. A lost acknowledgement requires refresh and inspection. No original peer invocation is replayed.

Five original section 7 README items are completed by the full contract and verification. All 424 original entries retain their text/order; 170 remain open. Version 1 remains prohibited until all original work is implemented and validated. No dependency upgrade, runtime-range change, database/schema migration, project license grant, credentialed provider call or npm publication is included.

Validation covers 338 source tests and 72 Chromium tests, plus lint, strict types, formatting, production builds and dependency audits. Final verified commit/tree/CI evidence is in `LLM_Recovery_Prompt.md`. Local browser availability is recorded honestly there; listing tests does not establish a browser pass.

See [ADR 0021](../architecture/0021-response-collection.md) for deadline/timeout semantics, cancellation, retained reservations, frozen evidence, revision lineage, replay, and recovery. Wider correction/supersession, fair scheduling, context budgets, artifacts, advanced recovery, accessibility, security, packaging and live account/model verification remain open.

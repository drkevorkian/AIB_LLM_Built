# v0.4.1 — Node 26 compatibility

Run the application on Node.js 26.10.0. Node 24 remains supported, and settings, workspace/thread management, relays, and bounded agent discussions retain their existing behavior.

## Changes

- Accept Node 26.10 or later within 26.x alongside Node 24.15 or later within 24.x.
- Select Node 26.10.0 in `.nvmrc` and update Node TypeScript declarations and the locked dependencies.
- Allow the pinned esbuild installation hook for the npm version bundled with Node 26.10.
- Test Node 24.19.0 and 26.10.0 on Linux, Windows, and macOS in CI; run Chromium workflows on Linux for both versions.
- Update setup instructions and runtime architecture notes to reflect the supported versions.

## Verification

A clean `npm ci`, strict TypeScript checks, formatting, the production build, 99 engine/service/provider-protocol tests, 12 Chromium UI tests, and the production dependency audit pass under Node 26.10.0. Node 24.19.0 also passes the same checks. Persistence coverage includes database migration, the SQLite writer lease, settings, deletion, and restart recovery; browser coverage runs the built service and includes an actual empty-workspace restart.

## Upgrade

Install Node 26.10.0, update this checkout, and run `npm ci`. Then run `npm run dev`, or use `npm run build` followed by `npm start`. If using nvm, run `nvm install` and `nvm use` inside the checkout first. No database schema change is required for this release.

Paid-provider account verification, browser-session transport, desktop packaging, and the other open README checklist items retain their existing status.

# v0.18.0 — Immediate human interjections

## Behavior

Publish an addressed Human interjection with normal/urgent priority while a response is active. Record interjection commits the message, event, observed work, and optional workspace pause immediately. Choose Pause new dispatches or Record only; priority is a retained human label, not queue ordering. Inspection and export disclose the original policy and recording-time counts. The message invokes no model and creates no response obligations.

Existing queued/active requests retain their snapshots, instructions, grants, deadlines, and response sets. Pause holds new dispatches while active work may finish. Resume continues the original work; to revise the task, Stop and ask a new question. Fresh questions include the recorded human input. UUID replay after a lost acknowledgement returns the original message without pausing resumed work again. Failed writes roll back the entire transition. Archives, source copying, deletion/redaction, and restart recovery retain their existing boundaries.

One original README checkbox is completed: immediate human-interjection event recording. All 424 entries retain their original text/order; 176 remain open. Version 1 remains blocked until every original item is fully implemented and validated.

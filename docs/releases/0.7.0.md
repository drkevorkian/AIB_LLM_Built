# v0.7.0 — Markdown, code, and source copying

Read formatted answers and code while retaining their original source. Each message can switch between Markdown and source views, copy its stored body, or copy an individual code block, including in archived workspaces.

## Changes

- Add CommonMark/GFM headings, emphasis, lists, blockquotes, tables, disabled task checkboxes, inline code, and fenced/indented code blocks.
- Keep message headings below the workspace heading. Code and wide tables scroll within the conversation and support keyboard focus on narrow screens in both themes.
- Add source/format controls and explicit message/code copying with accessible feedback. Missing or denied clipboard access leaves selectable text and opens source view for manual message copying.
- Preserve stored bodies, source context, reply links, author bindings, literal search, exports, workflow state, and consumed turns. Formatting and copying never invoke a model or interpret routing-looking text as a command.
- Keep streamed text literal until the attempt ends. Whole-message copying captures text at the click; later stream updates clear stale copy feedback. Failed partial code remains readable without hiding its failed status.
- Escape raw HTML, disable non-web/relative/credential-bearing links, and isolate permitted HTTP(S) links in a new tab. Image syntax becomes an alt-text placeholder without loading images or tracking pixels.
- Load the formatter separately, memoize unchanged bodies, and preserve source and conversation controls if the formatter fails to load or render.
- Tell live providers that Markdown is presentation only; coordinators still return exactly one validated action object, with any formatting inside its body string.
- Give each browser run a fresh temporary database to avoid inherited workspaces and accumulating test history.
- Keep quick consecutive sends in the accepted thread by waiting for refreshed history before enabling another send; retain a draft typed during that refresh.

## Upgrade

Stop the local service, update the checkout, and rebuild:

```sh
git pull --ff-only
npm ci
npm run build
npm start
```

Use Node 26.10 or newer in the 26.x series, or Node 24.15 or newer in the 24.x series. No database or room-document migration is required. Existing history, participant revisions, archives, and frozen snapshots retain their source strings.

## Limits

`Copy message` copies the stored body without interface labels; during streaming it copies text available at that click. `Copy code` copies parsed code without fences and may normalize line endings or include a final newline. Copy/source feedback resets on reload. A formatting load failure requires correcting the load problem and reloading.

Code is displayed without execution or syntax highlighting. Images and attachment previews, mathematical typesetting, diagrams, and internal footnote navigation remain planned. Only explicit HTTP(S) links without credentials are clickable. Exported Markdown retains original source; another viewer applies its own rendering rules. Existing provider, recovery, roster, search, and archive limits still apply.
